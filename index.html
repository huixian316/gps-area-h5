为什么不能直接对经纬度套鞋带公式？

经纬度是角度：同样 1° 经度差的实地长度随纬度按 cos φ 缩短。 直接把 (φ, λ) 当平面坐标求“面积”得到的是无物理意义的“平方度”，且随纬度严重畸变。 必须先经局部投影换算成米，再对平面坐标使用格林公式。

六步计算流程

  1. 取参考点：取第 1 个顶点为局部原点
    φ₀ = φ₁ ，λ₀ = λ₁
  2. 经纬度转弧度：
    φi = φi(°)·π/180
  3. 局部平面投影（米，WGS84 椭球曲率半径）：
    xi = N(φ₀)·cos φ₀·(λi − λ₀)
    yi = M(φ₀)·(φi − φ₀)
    M/N 为参考点处子午线/卯酉圈曲率半径。
  4. 格林公式离散形式：
    A = ½ · | Σi ( xiyi+1 − xi+1yi ) |
  5. 首尾闭合：j = (i+1) mod n，末边自动连回首点。
  6. 单位换算：1 公顷 = 10⁴ m²；1 亩 = 2000/3 m²；1 km² = 10⁶ m²。

完整推导、手算可验的数值示例、反例与精度分析见独立文档 math.html · 数学说明。

使用提示

  • 浏览器 Geolocation 仅在 HTTPS 下可用（本机调试环境除外），静态托管平台默认提供 HTTPS。
  • 野外实测：站在角点处点「＋ 记录GPS点」绕边界一周；或打开「自动记录」沿边行走，每移动 ≥5 m 自动加点。
  • 桌面端无 GPS 时，可打开「点图加点」在地图上手工放置顶点做演示。
  • 坐标系：Geolocation 输出与 Leaflet API 均为 WGS84 经纬度；底图仅用于显示，不影响计算。
  • 本工具纯静态、无后端：数据仅存于本设备浏览器 localStorage，不上传、不跨设备同步。
  • Leaflet 库与地图瓦片来自公共 CDN，首次打开需联网；离线时无底图，但计算功能可用。
数据仅保存在本设备浏览器的 localStorage：不上传服务器、不在设备间同步。换一台设备打开看到的是空记录，这是正常现象；清除浏览器数据也会删除记录，重要结果请另行记录。
